# ID2214 Programming for Data Science

## Dependencies
- `uv` package manager

## Installation
Get all packages (including Pyhon itself):
```
uv sync
```

Add new packages with:
```
uv add <package-name>
```

## Run
For any python file:
```
uv run my_file.py
```

Open a jupyter notebook in a web IDE:
```
uv run jupyter lab
```
